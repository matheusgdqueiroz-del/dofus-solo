# dofus-solo

Projeto pessoal relacionado a Dofus Solo. O repositorio serve para organizar ideias, estudos, anotacoes e possiveis implementacoes de apoio para acompanhar progresso, estrategias ou conteudos do jogo.

## Objetivos

- Centralizar anotacoes do projeto.
- Registrar ideias e melhorias futuras.
- Manter um historico de evolucao do planejamento.
- Transformar o material em uma pagina simples publicada no GitHub Pages.
