# Prompts do Workflow

Use estes arquivos como base do ciclo.

## Ordem padrão

1. `01-PLANNER.md`
2. `02-ARCHITECT.md`
3. `03-ORCHESTRATOR.md`
4. `04-WRITER.md`
5. voltar para `02-ARCHITECT.md`

## Regra de ouro

Toda resposta deve terminar com:

- próximo papel
- onde colar
- ação antes de colar
- prompt completo pronto para copiar

Se precisar revisão macro, use `05-PLANNER-REVIEW.md`.
